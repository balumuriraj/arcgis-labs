# Models

`lunar-module.glb` is the Apollo Lunar Module from [NASA 3D Resources](https://github.com/nasa/NASA-3D-Resources/tree/master/3D%20Models/Apollo%20Lunar%20Module), converted for the ArcGIS Maps SDK with glTF-Transform: Draco mesh compression and WebP textures removed (textures re-encoded as PNG, at most 1024 px), and simplified to about 57,000 triangles. Real size: about 6.4 m wide and 5.1 m tall, base at the origin.

NASA 3D Resources models are free to use without copyright; NASA's media guidelines ask that you don't imply NASA endorses the app.
